# AumPOS downloads

Installers and updates for AumPOS. This repository holds downloads only.

Get the newest version from **[Releases](https://github.com/BebbaApp/AumPOS-Updates/releases/latest)**:

| Device | File |
|---|---|
| Windows PC (Intel / AMD) | `AumPOS-Setup-x64.exe` |
| Windows PC (ARM, e.g. Surface, Snapdragon) | `AumPOS-Setup-arm64.exe` |
| Android tablet | `AumPOS.apk` |

Tills already running AumPOS find new versions themselves: **Launchpad → System → Install Update**.

Windows may warn that the installer is from an unknown publisher: choose *More info → Run anyway*.
